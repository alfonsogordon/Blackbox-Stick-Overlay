Overlay Studio updates

What's new?

The main new features, improvements and fixes, with the newest release first. For the small technical changes, see the full GitHub history.

v1.0.4 Latest

13 November 2026 · Flight-mode display

  • The existing Flight Modes element now shows readable Betaflight mode names instead of raw numbers, including ACRO, ANGLE, HORIZON and GPS RESCUE.
  • Multiple active mode flags are shown together; unfamiliar flags remain visible as hexadecimal values.

v1.0.3

13 November 2026 · Changelog

  • Added a dedicated changelog linked from the About page, showing the main updates by version.

v1.0.2

13 November 2026 · Export display

  • Redesigned the export confirmation text to make flight details, output format and estimated time easier to understand.
  • Resolved a GitHub Pages deployment issue so the release could go live.

v1.0.1

13 November 2026 · Movement and export

  • Fixed the graphic movement lock so HUD artwork moves together as one image.
  • Moved the lock setting into the graphics movement controls.
  • Made the export confirmation appear immediately, with estimates learned from previous exports rather than lengthy sampling.

v1.0.0

13 November 2026 · First major release

  • Introduced native portrait HUD layouts for 9:16 and 3:4 video, with a more reliable scrolling preview.
  • Added individually selectable and independently animated graphic layers across supported themes.
  • Added the welcome guide for first-time users, with an option to reopen it.
  • Improved theme controls, resets and neon glow placement.
  • Improved export estimates and the overall export experience.

v0.15.x

12 November 2026 · Major pre-release improvements

  • Introduced improved DJI and GoPro camera-motion matching to help synchronise overlays with recorded video.
  • Added the About page, welcome-guide work and early custom stick-pointer options.
  • Improved armed/disarmed time handling and overlay timing controls.

v0.14.x

Earlier development · Major highlights

  • Introduced more HUD themes, OSD layouts, custom artwork and reusable presets.
  • Expanded available telemetry, battery gauges, GPS compass and other flight instruments.
  • Improved preview element selection, dragging, resizing and custom colours.
  • Added transparent MOV export improvements, large-file splitting and export diagnostics.
